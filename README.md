# Portfolio

Personal portfolio website built with HTML, CSS and vanilla JavaScript. It presents my background, technical stack, projects and contact links, with Portuguese and English content.

## Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- Static hosting (Vercel configuration included)

## Running locally

Open `index.html` directly in a browser, or serve the folder with:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Structure

```text
portfolio/
├── index.html
├── assets/
│   ├── css/
│   └── js/
└── README.md
```

## Notes

- The site is a personal presentation layer; the technical details of each project are documented in the respective repositories.
- Project links point to the public GitHub repositories.
